# Pre-Event Baseline

## Event-window rule

The verified competition rule required a new event project and a public repository created during the event window. To avoid misrepresenting pre-event work, SourceLoop was built in a new empty repository after the official opening.

That workspace was not used as a Git ancestor, source overlay, package, submodule, asset source, template, test source, runtime dependency, or shared worktree.

## Before SourceLoop

No SourceLoop repository, source file, course data, UI screenshot, test fixture, or public history existed before `2026-11-13 10:00:51 HKT`.

The first repository commit is:

```text
4fe0cbc  docs: establish clean-room SourceLoop specification
```

The team’s product decision was therefore to solve the same learning problem with a smaller, complete, independently built product rather than to relabel an earlier implementation as event work.
